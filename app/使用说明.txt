HAAVK Launcher · v1.0.4 · DeepSeek 4K 启动动画

开始使用
1. 完整发行包约 2 GB，已经包含全部视频。请完整解压，保留本目录中的 EXE、assets、videos 和脚本。
2. 双击“创建DeepSeek桌面快捷方式.vbs”，创建 DeepSeek - HAAVK 01 / 02 / 03 三个桌面入口。
3. 双击任意入口：以原声播放对应动画，片尾通过默认浏览器打开 https://chat.deepseek.com/。
同名快捷方式已存在时会添加序号；移动整个文件夹后请重新创建入口。
v1.0.3 起已下架 Codex 入口。升级用户请使用新版完整文件夹，并自行删除旧的 Codex - HAAVK 快捷方式。

源码下载与完整包的区别
GitHub 自动生成的 Source code 压缩包或 git clone 不包含 MP4。
源码用户须先在仓库根目录运行：
  powershell -NoProfile -ExecutionPolicy Bypass -File .\app\source\download-videos.ps1
脚本根据 app/videos/manifest.json 下载视频并校验文件大小和 SHA-256；已有且校验正确的文件会跳过。
完整发行包用户无需再次下载。不要仅复制 EXE，videos 和 assets 必须与它放在一起。

三个 4K 文件
01：HAAVK_01.mp4，33.0 秒，708,946,980 字节。
02：HAAVK_02.mp4，30.8 秒，743,761,309 字节。
03：HAAVK_03.mp4，29.8 秒，657,647,987 字节。
使用作者提供的 3840×2160、30fps、H.264 + AAC 文件，保留完整时长、音轨和文件字节，没有重新编码。
包内文件与发布页的 HAAVK_01_4K.mp4 等对应文件内容相同，仅文件名不同。既有 1080p 文件未修改。
普通窗口可能小于 4K，只缩放显示，不改变文件分辨率；最大化按当前显示器尺寸显示并保持画面比例。

操作
- 等待片尾：自动打开 DeepSeek。
- Esc：跳过剩余动画并打开 DeepSeek；预览模式只结束预览。
- Enter：不触发操作。
- 右上角最小化：动画和声音继续播放，片尾仍打开目标。
- 右上角最大化/还原：切换窗口大小，保持画面比例。
- 右上角 × 或 Alt+F4：取消本次启动，不打开网页。
- 普通窗口中按住视频区域拖动：移动窗口。
原音轨始终开启；实际音量取决于 Windows 音量和输出设备。

预览与故障
双击“预览 HAAVK 01.vbs”、“预览 HAAVK 02.vbs”或“预览 HAAVK 03.vbs”只播放动画，不打开网站。
视频无法播放时，中央显示错误提示；Esc 可继续打开 DeepSeek，预览模式则关闭，× 可取消。
网页需要可用的默认浏览器和网络连接，网站登录由浏览器和 DeepSeek 处理。
